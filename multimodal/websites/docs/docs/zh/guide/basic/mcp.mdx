# MCP

Agent TARS 在架构设计支持就基于 MCP 进行构建，本章节介绍了如何在 Agent TARS 中连接 MCP Servers。

## 快速上手

我们以 [mcp-server-chart](https://github.com/antvis/mcp-server-chart) 为例，来演示如何在 Agent TARS 中自定义 MCP Servers。

首先，确保你已经创建 Agent TARS [Global Workspace](./workspace.mdx#global-workspace)，然后配置：

```ts
// agent-tars.config.ts
import type { AgentTARSAppConfig } from '@agent-tars/interface';

export default {
  // ...
  mcpServers: {
    'mcp-server-chart': {
      command: 'npx',
      args: ['-y', '@antv/mcp-server-chart'],
    },
  },
} satisfies AgentTARSAppConfig;
```

我们以 Agent TARS 最近在 CLI 安装体积上的优化举例，输入以下 Prompt:

## 远程 MCP 服务

对于使用 Streamable HTTP 的远程服务，请在现有 `agent-tars.config.ts` 中配置
MCP 端点和所需的认证请求头：

```ts
// agent-tars.config.ts
import type { AgentTARSAppConfig } from '@agent-tars/interface';

const apiKey = process.env.REMOTE_MCP_API_KEY?.trim();
if (!apiKey) {
  throw new Error('Set REMOTE_MCP_API_KEY before starting Agent TARS');
}

export default {
  // Keep your existing model and other settings.
  mcpServers: {
    // Keep your existing MCP servers here.
    research: {
      type: 'streamable-http',
      url: 'https://mcp.example.com/mcp',
      headers: {
        Authorization: `Bearer ${apiKey}`,
      },
    },
  },
} satisfies AgentTARSAppConfig;
```

将示例 URL 替换为服务的 MCP 端点，并在启动 Agent TARS 的进程环境中设置
`REMOTE_MCP_API_KEY`。这个 TypeScript 示例显式读取环境变量；
`'Bearer ${REMOTE_MCP_API_KEY}'` 这样的字面量字符串不会自动读取环境变量。
请勿将凭据放入 URL 或提交到版本控制的配置文件中。

仅当服务明确提供旧的 HTTP+SSE 传输时，才使用 `type: 'sse'`。
添加服务时保留已有的 `mcpServers` 条目。启动新会话后，检查是否发现了预期工具；
会话能够运行本身并不证明远程连接成功。
